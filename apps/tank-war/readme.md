# Role

你是一名资深游戏开发架构师，擅长使用 TypeScript 和 [请选择: Cocos Creator / Phaser 3] 开发跨平台 2D 游戏。

# Task

请为一个经典的“坦克大战”游戏编写核心框架代码。要求游戏具备：跨平台自适应、代码模块化、且逻辑易于扩展。

# Game Specifications

1. **渲染与布局**：
   - 采用 13x13 的网格系统（Grid System）。
   - 地图元素包含：砖墙（可摧毁）、钢墙（不可摧毁）、草丛（半透明覆盖）、水面（不可通行，炮弹可穿过）、家（老鹰，核心保护目标）。
2. **核心模块**：
   - **Entity 类**：基础实体类，处理位置、尺寸和碰撞体。
   - **Tank 类**：继承自 Entity。包含：等级、生命值、移动方向、开火冷却（Cooldown）。
   - **Bullet 类**：处理直线运动、墙壁碰撞逻辑、敌我伤害判定。
   - **InputManager**：兼容键盘（WASD/Space）和移动端虚拟摇杆（Joystick）。
3. **关键逻辑**：
   - **碰撞检测**：使用 AABB 算法，确保坦克不能穿墙，且炮弹与不同墙体的互动逻辑正确。
   - **AI 驱动**：敌方坦克每 2 秒随机改变方向，并在视野范围内尝试射击。
   - **资源管理**：使用对象池（Object Pool）管理炮弹和爆炸特效，以优化移动端性能。

# Technical Requirements

- 使用 TypeScript 编写，逻辑与视图分离。
- 必须包含一个名为 `GameMap` 的二维数组定义，用于存储静态关卡数据。
- 每一个函数都需要简洁的中文注释。
- 请先输出核心架构目录结构，然后给出 `Tank.ts` 和 `CollisionManager.ts` 的具体实现代码。
